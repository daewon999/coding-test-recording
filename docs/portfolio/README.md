# 코딩 테스트 기록 서비스 — 포트폴리오 원자료

문제 정보와 풀이 기록을 저장하고 학습 과정을 돌아보기 위한 서비스입니다.

## 기록 원칙

- 구현 목록뿐 아니라 해결하려는 문제, 설계 선택과 이유, 실제 검증 결과를 기록합니다.
- 제안·구현·검증 완료를 구분합니다. 확인하지 않은 성능 개선이나 장애를 성과로 적지 않습니다.
- 기능 작업 후 개발 기록에 날짜별로 추가하고, 깊게 설명할 사례는 별도 문서로 정리합니다.

## 기록 위치

- [개발 기록](development-log.md)
- [기술 사례](case-studies/README.md)

## 기술 구성

- 프론트엔드: React, TypeScript, Vite, Tailwind CSS
- 백엔드: Java, Spring Boot, JPA
- 데이터 모델: 문제(Problem)와 풀이(Solution) 분리

## 앞으로 다룰 주제

1. 전체·정답·오답 필터의 조회 방식 선택
2. 같은 문제에 여러 풀이를 저장하는 구조와 저장 일관성
3. 문제별 풀이 이력과 두 풀이 비교

각 주제는 구현과 검증 후 기술 사례로 정리합니다.
